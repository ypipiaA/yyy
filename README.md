# FitTrack - 健身助手

一个简洁的网页健身程序，支持训练计划生成、训练记录、休息计时和进度统计。数据保存在浏览器本地，无需服务器。

## 功能

- **训练计划**：根据目标（增肌/减脂/力量/耐力）、每周天数和经验水平自动生成训练计划
- **开始训练**：选择训练日，记录每组重量、次数，标记完成
- **休息计时**：60秒 / 90秒 / 2分钟 / 3分钟预设，或自定义时长，到时震动提醒
- **进度统计**：训练次数、本周训练、连续天数、总训练量，以及每周频率和动作进步曲线

## 使用方法

1. 用浏览器打开 `index.html`（双击即可）
2. 在「训练计划」页选择目标并生成计划，点击「保存计划」
3. 在「开始训练」页选择训练日，填写每组数据后点击「完成训练」
4. 组间休息时使用「休息计时」
5. 在「进度统计」查看训练数据和图表

## 技术说明

- 纯 HTML / CSS / JavaScript，无需安装 Node.js
- 数据存储在 `localStorage`，清除浏览器数据会丢失记录
- 图表使用 [Chart.js](https://www.chartjs.org/)（CDN 加载，需联网）
